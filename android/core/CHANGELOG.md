# Changelog

What's new in each update of Radon Player, the newest at the top. Everything the app does is in **Features**.

## 3.2.7 · November 2026
- **Covers stay put on the phone:** WAVs are tagged on the phone the way the PC does it (by hand: their ID3 chunk, where the cover is, and LIST INFO, every other chunk kept), not through the tag library, which could read only a WAV's LIST INFO and write it back without its ID3 chunk, cover and all. Any other file whose cover the tag library drops while its other tags change gets it put straight back.
- **Unreleased songs keep their covers:** the phone read the cover inside FLACs only, so to Tags & covers match every MP3, M4A and WAV there looked as if it had none, and each sync wrote the PC's cover into it through the tag library (which could leave it with none at all). The phone now reads the cover in any file, a song that has one is never given another, and a folder named Unreleased is always left alone by a sync, on both devices, whether it's in Folders sync leaves alone or not.
- **Filled-in tags are left alone:** Tags & covers match only fills in what a song is missing now (a tag with nothing in it, a cover when it has none); it never changes a tag that's filled in or replaces a cover. Tags change only when you edit them (the Tagger, Edit tags) or run a scan to change them. The genres the app looks up for its downloads with none aren't sent to your other device either.

- **Settings resets for the one scan:** Reset moods works the moods out again from what was heard and read (nothing heard again) and the next Scan moods writes them in; Reset sound scan and Remove all moods are followed by Scan moods too.
